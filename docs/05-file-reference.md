# File Reference

Every file that matters, one line each, organized by directory. Build
artifacts (`__pycache__/`, `.pytest_cache/`, `.ruff_cache/`,
`node_modules/`, `.next/`, `tsconfig.tsbuildinfo`) are omitted — regenerated,
never hand-edited, already gitignored.

## Root

| File | Purpose |
|---|---|
| `README.md` | Project spec: what it is, the two hard judgment calls, def-of-done checklist. Source of truth for scope. |
| `config.py` | All env-driven config in one place: FDA URL, `DATABASE_URL`, OpenAI key/model, confidence/fuzzy thresholds, data file paths. Plain `os.environ` + `python-dotenv`, no validation framework. |
| `run_pipeline.py` | Orchestrates pipeline Stages 1-4 in order; the only thing you run to (re)build the reference DB. Logs row/flag counts per stage. |
| `pyproject.toml` | `uv`-managed Python project: deps, dev-deps (pytest, ruff), ruff config (line-length 100, excludes `db/alembic/versions`), pytest config. |
| `uv.lock` | Locked dependency versions — committed, don't hand-edit. |
| `alembic.ini` | Alembic config; `script_location` points at `db/alembic`. The `sqlalchemy.url` placeholder here is overridden at runtime by `db/alembic/env.py`. |
| `docker-compose.yml` | Full local stack: `db` (Postgres 16, healthchecked), `api` (builds `api/Dockerfile`), `web` (builds `web/Dockerfile`). |
| `.env.example` | Template for `.env` — DB URL, OpenAI key/model, thresholds. Never contains a real key. |
| `.env` | Real secrets (gitignored). Contains the actual `OPENAI_API_KEY` used for live pipeline/API runs. |
| `.dockerignore` | Root build-context excludes for `api/Dockerfile` (`.venv`, `.git`, `web/`, `data/`, `tests/`, `.env`). |
| `.gitignore` | Excludes venvs, caches, `.env`, generated `data/*` JSON/HTML, `node_modules`, `.next`, IDE files, Playwright MCP artifacts. |
| `.python-version` | Pins `3.11` for tools that read this file (pyenv, uv). |

## `pipeline/` — Part A, offline batch (see `docs/01-pipeline.md`)

| File | Purpose |
|---|---|
| `ingest.py` | Stage 1. `fetch_and_save()` — one HTTP GET to the FDA page, saves timestamped raw HTML, fails loudly on non-200. |
| `parse.py` | Stage 2. `parse_html()` — raw HTML to `list[IngredientRawRow]`. Owns the `IngredientRawRow`/`AgencyAction` schema. Handles `<p>`/`<br>` cell variants, N/A synonyms, multi-codes, relative-URL resolution. |
| `normalize.py` | Stage 3. `normalize_rows()` — OpenAI structured-output classification into 7 fixed statuses, grounded in hardcoded `CATEGORY_LEGEND`. Owns the idempotency cache (keyed on content hash, checked against `extraction_staging`). |
| `load.py` | Stage 4. `load_normalized()` — idempotent upsert-by-name into `ingredients` + `ingredient_regulatory_status`. |
| `__init__.py` | Empty; marks `pipeline` as a package. |

## `api/` — Part B backend (see `docs/03-api.md`)

| File | Purpose |
|---|---|
| `main.py` | FastAPI app: CORS setup, `GET /` health check, `POST /api/check` (the entire backend surface). |
| `match.py` | The matching cascade: `split_candidates()` (paren-aware), exact/synonym/fuzzy/LLM tiers, `check_ingredients()`, `build_summary()`. |
| `models.py` | Pydantic wire schemas: `CheckRequest` (with the 5000-char cap), `IngredientCheckResult`, `CheckResponse`. |
| `Dockerfile` | Builds the API image: `uv sync --frozen --no-dev`, `ENV UV_NO_SYNC=1` (so the container doesn't re-pull dev deps at boot), `CMD` runs `alembic upgrade head` then `uvicorn`. |
| `__init__.py` | Empty; marks `api` as a package. |

## `db/` — shared DB layer (see `docs/02-database.md`)

| File | Purpose |
|---|---|
| `models.py` | SQLAlchemy ORM: `Ingredient`, `IngredientRegulatoryStatus`, `ExtractionStaging`. |
| `session.py` | `get_session()` (script context manager, commit/rollback) and `get_db()` (FastAPI `Depends()` generator). The only place `engine`/`Session` get constructed. |
| `alembic/env.py` | Alembic runtime config. Inserts repo root onto `sys.path`, imports `config.DATABASE_URL` and overrides `alembic.ini`'s URL with it, wires `target_metadata = Base.metadata` for real autogenerate diffs. |
| `alembic/script.py.mako` | Alembic's template for new migration files (untouched default). |
| `alembic/README` | Alembic's own boilerplate readme (untouched default). |
| `alembic/versions/*.py` | Generated migrations. Currently one: initial schema (`ingredients`, `ingredient_regulatory_status`, `extraction_staging`). Excluded from ruff linting — autogenerated, not hand-styled. |
| `__init__.py` | Empty; marks `db` as a package. |

## `tests/` — pytest, backend only

| File | Purpose |
|---|---|
| `conftest.py` | `db_session` fixture: truncates the three pipeline tables before/after each test, yields a real session. Tests requiring DB access need a live Postgres (ARRAY/JSONB aren't SQLite-portable). |
| `test_parse.py` | Stage 2 fixtures: multi-line synonyms/actions via `<p>` tags, absolute-URL resolution, italicized name + N/A synonym + multi-category row, malformed-row skip-not-crash. |
| `test_match.py` | Matching cascade: candidate splitting (incl. paren-aware), each tier in isolation (exact/synonym/fuzzy/LLM-fallback), LLM-outage resilience, summary counting. |
| `test_api.py` | `TestClient` against the real FastAPI app: health check, full `/api/check` round-trip with seeded DB data, oversized-payload rejection. |
| `__init__.py` | Empty; marks `tests` as a package. |

## `.github/workflows/`

| File | Purpose |
|---|---|
| `ci.yml` | Two jobs. `backend`: spins up a real Postgres service container, `uv sync`, `ruff check`, `alembic upgrade head`, `pytest`. `frontend`: `pnpm install`, `eslint`, `tsc --noEmit`, `pnpm build`. |

## `web/` — Part B frontend (see `docs/04-frontend.md`)

| File | Purpose |
|---|---|
| `app/layout.tsx` | Root HTML shell, fonts, page metadata (title/description). |
| `app/page.tsx` | The one page. Owns request/response state, wires `IngredientInput` to `checkIngredients()` to `ResultsList`. |
| `app/globals.css` | Tailwind entry point + global styles (default `create-next-app` output, unmodified beyond Tailwind setup). |
| `app/favicon.ico` | Default Next.js favicon (unmodified). |
| `components/IngredientInput.tsx` | Paste/photo mode toggle, editable textarea, client-side OCR wiring, file validation (type + 5MB cap), submit button. |
| `components/ResultsList.tsx` | Pure render: summary line + one card per result, status badge (label + color lookup tables), reasoning, citation link. |
| `utils/ocr.ts` | `extractTextFromImage()` — the only place image bytes exist; Tesseract.js worker lifecycle (create, recognize, always terminate). |
| `lib/api.ts` | `checkIngredients()` — the only `fetch()` call in the frontend, typed request/response, `NEXT_PUBLIC_API_URL` env override with `localhost:8000` default. |
| `Dockerfile` | Builds the web image: `pnpm install --frozen-lockfile`, `pnpm build`, `CMD ["pnpm", "start"]`. |
| `.dockerignore` | Excludes `node_modules/`, `.next/`, `out/` from the web build context. |
| `package.json` | Deps (`next`, `react`, `tesseract.js`) + devDeps (TypeScript, Tailwind, ESLint) + scripts (`dev`/`build`/`start`/`lint`). |
| `pnpm-lock.yaml` | Locked JS dependency versions — committed. |
| `pnpm-workspace.yaml` | `allowBuilds` for packages needing postinstall scripts (`sharp`, `unrs-resolver`, `tesseract.js`) — pnpm's newer supply-chain-safety gate. |
| `tsconfig.json` | TypeScript config, `@/*` import alias to repo-relative paths (no `src/` dir). |
| `next.config.ts` | Next.js config (default, unmodified). |
| `eslint.config.mjs` | ESLint flat config (default `create-next-app` output, `next/core-web-vitals` + TypeScript rules). |
| `postcss.config.mjs` | Tailwind's PostCSS plugin wiring (default). |
| `public/*.svg` | Default `create-next-app` placeholder icons — unused after the page rewrite, harmless, not cleaned up. |
| `README.md` | Default `create-next-app` boilerplate readme — not project-specific, superseded by root `README.md` and this `docs/` tree. |

## `data/` — pipeline artifacts (gitignored except `.gitkeep`)

| Path | Purpose |
|---|---|
| `raw/*.html` | Stage 1 output: untouched FDA HTML, timestamped. The audit trail. |
| `parsed/ingredients_raw.json` | Stage 2 output: parsed `IngredientRawRow[]`, still unnormalized. |
| `normalized/ingredients_normalized.json` | Stage 3 output: `NormalizedIngredient[]`, mirrors what got written to `extraction_staging`. |
| `output/` | Reserved, currently unused by any stage. |
| `*/.gitkeep` | Keeps the empty directory structure tracked in git despite the generated contents being ignored. |
